## 1. 捷運大廳 (n_0000, model nvidia/nemotron-3-ultra-550b-a55b)

- 核冬天第十年的寒風從地面的通風井灌入捷運大廳，帶著乾裂的塵土與淡淡的鏽味。大廳的應急燈閃爍著病態的黃光，將眾人的影子拉得忽長忽短。
- 牆角堆疊的塑膠桶只剩下三分之一，裡頭濁水搖晃，那是全聚落四十七條命還能撐七天的命脈。阿岳緊了緊揹包帶，指節因用力而發白。
- **陳姐**：阿岳，別光盯著水桶發呆。淨水機的壓力閥壞了，沒備品換不回來，七天後這大廳就得變成冰庫。
- **陳姐**：你今早出發，往北走舊市政府地下街，那邊有批舊世代的工業閥體沒被撿走。小灰會跟著你，別讓他出事。
- **小灰**：姐、姐姐……我、我揹包裡還有兩罐壓縮餅乾，夠、夠我們撐、撐一天……
- **陳姐**：夠就好。天黑前回來，聽見沒？

options: 「放心，我會帶著小灰平安回來。」 / 「要不我自己去，小灰留下比較安全。」 / 「先讓我檢查裝備，順道問問有沒有地圖。」 / 「七天太趕了，能不能先想別辦法撐久一點？」

- 崩塌的紀念堂拱頂下，鋼筋像斷裂的脊椎刺向灰白天空。通往舊市政府地下街的入口被數十噸碎石封死，唯一的路是繞向側翼那棟傾頹的百貨大樓，穿過其地下室連通管道——那意味著更深層、更濃烈的輻射沉澱區。

- 門軸發出撕心裂肺的金屬哀鳴，黑暗如實體般撲面而來，夾雜著濕腐黴味與一絲若有若無的——氯氣味？計量器聲音驟變，從間歇性蜂鳴轉為連續單調長音，紅燈閃爍頻率加快，電池電量狂瀉。

options: 強行衝入地下管道，賭氯氣味是淨水設施殘留 / 退回地面尋找繞路，哪怕耗費雙倍時間 / 服用僅有的兩片碘片硬抗輻射繼續前進 / 啟動求救信標，賭陳姐能收到訊號派人接應

## 6. 地面廢墟 (n_0005, model nvidia/nemotron-3-ultra-550b-a55b)

- 他將濾芯塞進揹包側袋，動作粗暴卻帶著一絲笨拙的溫柔。通訊器另一端，電流聲裡夾雜著壓抑的吸鼻聲，彷彿隔著幾十噸混凝土與輻射塵，也能聞到那股濕腐的黴味。

## 8. 地面廢墟 (n_0007, model nvidia/nemotron-3-ultra-550b-a55b)

> **阿岳** (free)：暴風雪來了，我還是硬闖崩塌的隧道想搶先拿到零件。

- 風聲在廢墟縫隙中尖嘯，捲著銳利的冰晶與灰白輻射塵，像無數隱形的刀刃刮過暴露的皮膚。阿岳聽見陳姐的聲音，卻連回應的力氣都沒有，喉嚨裡只擠出破碎的氣音。
- 他一腳踏入鋼門門縫，門軸發出慘烈的金屬呻吟。門內是個不大的裝置間，牆壁掛著剝落的標識：「舊市政府地下街・增壓泵站・維護通道」。中央矗立著一臺笨重的舊世代淨水核心模組，指示燈以極緩的頻率閃爍著微弱的綠光——它還活著。
- 目標壓力閥就安裝在模組側面的銅質管路上，手掌大小，表面覆著一層薄霜。阿岳顫抖著伸出手，指尖剛觸到冰冷金屬，視野便徹底白了。計量器發出最後一聲尖銳長鳴，隨後徹底熄滅。他感覺自己像塊石頭一樣砸在地上，聽見自己肋骨碎裂的聲音，或許只是幻覺。
- **陳姐**：（通訊器，聲音撕裂般鋒利）阿岳！回話！定位顯示你在泵站內部……小灰哭著要衝回來找你，我鎖了大廳門……你給我撐住……
- **小灰**：（通訊器背景，哭喊聲模糊）哥……哥哥……別死……別丟下我……
- 意識像潮水般退去，最後留下的畫面是那支壓力閥在綠光中靜靜轉動，彷彿在等待某雙有力的手將它擰下，帶回地底等待的幾十張渴臉。暴風雪仍在門外嘶吼，沒人知道這條隧道能否撐到天亮。
