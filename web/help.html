常見問題

遊戲裡的錯誤訊息旁有「說明」連結，會帶你到對應的段落。

輝達伺服器忙碌金鑰被拒絕連不上轉送服務 網路或連線中斷儲存空間已滿

輝達伺服器忙碌

看到什麼
狀態列顯示「輝達共用伺服器擁擠」並倒數重試，或最後出現「所有模型都暫時無法回應」。
為什麼
build.nvidia.com 的免費共用伺服器同時太多人使用，回覆 429（請求太多）或 503（暫時無法服務）。不是金鑰或電腦的問題。
怎麼做
  1. 先等倒數跑完，遊戲會自己再試；想馬上試就按「立即重試」。
  2. 失敗後按失敗訊息旁的「重試」，會用同一個輸入重送，不用重打。
  3. 常常遇到時，打開設定的「連線」區，把「忙碌時最多等」改成「10 分鐘」或「一直等到成功」。
  4. 想早點有回應，把「模型偏好」改成「速度優先」，第一個模型一忙就換下一個。
  5. 標題畫面的燈號或遊戲工具列的圓點變紅時，可以先從節點樹玩已經寫好的分支，晚點再寫新的。

金鑰被拒絕

看到什麼
「請先到設定填寫輝達 API Key」、「輝達拒絕了這把金鑰」或「金鑰格式不對」。
為什麼
金鑰沒填、貼錯（多了空格或少了字），或已經過期、被刪除。
怎麼做
  1. 到 build.nvidia.com 登入，產生一把新的金鑰，它以 nvapi- 開頭。
  2. 打開設定的「連線」區，把金鑰貼進「輝達 API Key」，按「儲存」。錯誤訊息旁的「開啟設定」會直接跳到這一欄。
  3. 貼上時注意前後不要多出空格。
  4. 回到遊戲按「重試」。

連不上轉送服務（網頁版）

看到什麼
「請先到設定填寫轉送網址」、「連不上轉送網址」、「轉送服務不接受這個網站來源」或「轉送網址格式不對」。
為什麼
瀏覽器不能直接呼叫輝達 API，網頁版要經過轉送服務。網址填錯、轉送服務停了，或轉送服務沒有允許這個網站，都會連不上。伺服器版沒有這一欄，不會遇到。
怎麼做
  1. 打開設定的「連線」區，看「轉送網址」。不確定時清空後按「儲存」，會改用內建網址。
  2. 用自己部署的轉送服務時，確認網址以 https:// 開頭，而且服務還在執行。
  3. 出現「不接受這個網站來源」時，把目前這個網站的網址加進轉送服務的 ALLOWED_ORIGINS 允許清單。
  4. 修好後回到遊戲按「重試」。

網路或連線中斷

看到什麼
畫面頂端出現「網路已中斷」橫幅，或訊息「連線中斷，這一輪沒有完成」、「連不上遊戲伺服器」。
為什麼
網路斷了、手機切到背景太久，或伺服器版的遊戲伺服器被關掉了。
怎麼做
  1. 確認網路恢復；恢復後遊戲會自動重送剛才的輸入。
  2. 沒有自動重送就按「重試」。中斷後 10 分鐘內重試，已收到的台詞會保留，從中斷處接著寫。
  3. 伺服器版：確認「啟動千枝物語.bat」開的視窗還在；被關掉了就再執行一次，然後重新整理頁面。

儲存空間已滿（網頁版）

看到什麼
「瀏覽器的儲存空間已滿，這次的內容沒有存下來」。
為什麼
網頁版把故事、圖片與存檔都放在瀏覽器裡，圖片多了會用完瀏覽器分給這個網站的空間。無痕視窗的空間更小。
怎麼做
  1. 在標題畫面按「下載進度到電腦」，先把全部進度備份成 zip。
  2. 打開「管理故事」，刪掉不再玩的故事騰出空間。
  3. 回到遊戲重做剛才的操作。
  4. 之後想找回刪掉的故事，把 zip 解壓縮，再用「讀取資料夾進度」選那個資料夾。
  5. 建議用一般視窗玩，不要用無痕視窗。

Common problems

Error messages in the game have a "Help" link that brings you to the matching section.

NVIDIA servers busyKey rejectedRelay unreachable Network or connection lostStorage full

NVIDIA servers busy

What you see
The status line says the shared NVIDIA servers are crowded and counts down to a retry, or ends with "No model can answer right now".
Why
Too many people are using the free shared servers at build.nvidia.com, which answer 429 (too many requests) or 503 (temporarily unavailable). Your key and computer are fine.
What to do
  1. Let the countdown finish and the game tries again by itself; press "Retry now" to try at once.
  2. After a failure, press "Retry" next to the error; it sends the same input again.
  3. If it happens often, open the Connection part of Settings and set "Wait when busy" to 10 minutes or "Until it works".
  4. For a faster answer, set "Model choice" to "Speed first" so the next model takes over as soon as the first is busy.
  5. When the light on the title screen or the dot in the game toolbar turns red, play branches that are already written from the tree and write new ones later.

Key rejected

What you see
"Enter your NVIDIA API key in Settings first", "NVIDIA rejected this key" or "Invalid key".
Why
The key is missing, was pasted wrong (extra spaces or missing characters), or has expired or been deleted.
What to do
  1. Sign in at build.nvidia.com and create a new key; it starts with nvapi-.
  2. Open the Connection part of Settings, paste it into "NVIDIA API key" and press Save. "Open Settings" next to the error jumps to this field.
  3. Make sure no spaces came along before or after the key.
  4. Go back to the game and press "Retry".

Relay unreachable (web version)

What you see
"Enter a relay URL in Settings first", "Cannot reach the relay URL", a message that the relay does not accept this site, or "Invalid relay URL".
Why
Browsers cannot call the NVIDIA API directly, so the web version goes through a relay. A wrong URL, a stopped relay, or a relay that does not allow this site all end here. The server version has no relay and never shows this.
What to do
  1. Open the Connection part of Settings and check "Relay URL". If unsure, clear it and press Save to use the built-in relay.
  2. With your own relay, check that the URL starts with https:// and that the relay is running.
  3. If the relay does not accept this site, add this site's address to the relay's ALLOWED_ORIGINS list.
  4. Go back to the game and press "Retry".

Network or connection lost

What you see
A "You are offline" banner at the top, or "The connection dropped; this turn did not finish" or "Cannot reach the game server".
Why
The network went down, the phone stayed in the background too long, or the server version's game server was closed.
What to do
  1. Wait for the network to come back; the game then sends your last input again by itself.
  2. If it does not, press "Retry". Within 10 minutes of the break, the lines already received are kept and the story goes on from there.
  3. Server version: check that the window opened by 啟動千枝物語.bat is still there; if it was closed, run it again and reload the page.

Storage full (web version)

What you see
"The browser storage is full; this was not saved".
Why
The web version keeps stories, pictures and saves in the browser, and pictures use up the space the browser gives this site. Private windows get even less.
What to do
  1. On the title screen, press "Download Progress" to back everything up as a zip.
  2. Open "Manage Stories" and delete stories you no longer play.
  3. Go back to the game and do it again.
  4. To bring a deleted story back later, unzip the backup and pick the folder with "Load Progress Folder".
  5. Play in a normal window rather than a private one.
